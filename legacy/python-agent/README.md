# Legacy Python agent

This directory preserves the former FastAPI/Python desktop agent, its tests, packaging tools and historical documentation. The supported desktop application lives in [`../../desktop/`](../../desktop/README.md); its shared React editor is in [`../../frontend/`](../../frontend/).

The old code is kept for reference and migration work. It is excluded from the active desktop CI and GitHub Release workflow. Its historical guides under `docs/` describe the Python distribution and should not be used to install current 3Decks.
