# Lyrics and page templates

For the user workflow, see [Usage](../../../docs/USAGE.md). This reference covers
how the desktop provides synchronized lyrics and creates template pages.

## Templates and setup

**Add a page** offers blank, lyrics, notifications, windows, OBS and performance
templates. Each becomes a normal editable page; no permission or external service
is activated by choosing a template.

The bundled configuration includes a music/lyrics page. Setup offers the lyrics
feature and can add its page when missing, without replacing existing pages.
At the 12-page limit, the user must free a slot first.

The lyrics dashboard has a configurable accent and 2–5 visible lines. The console
wraps the active line using native font measurements. Seeking is available when
the player provides duration/position and supports it.

## Providers and privacy

Online lookup is disabled by default. Enabling it sends track title, artist and
available album/duration metadata to LRCLIB from the desktop. The console receives
only bounded timestamped text. macOS supplies metadata through its native media
adapters; Windows supplies it through GSMTC. Linux lacks a native media provider.

Disabling online lookup hides downloaded cache results; local LRC files remain
usable. Unsynchronized, instrumental and missing results have explicit states.
No lyrics are generated by the app.

## Local files and cache

The app's configuration directory contains `lyrics/`. A local file is named
`<track-key>.lrc`; downloaded timestamped lines use `<track-key>.json`.
The key is the hexadecimal SHA-256 of UTF-8 text:

```text
lowercase_title + NUL + lowercase_artist + NUL + lowercase_album + NUL + duration_seconds
```

Title and artist are trimmed before deriving the key. Unknown album is an empty
string and unknown duration is `0`. Local LRC files take priority over online data.
The key derivation lives in `src-tauri/src/features/lyrics.rs`.

## Transport limits

Responses/files are limited to 256 KiB, then to 256 lines of 120 UTF-8 bytes each.
A song is sent as one `media.lyrics` frame within the 64 KiB transport limit.
The console tracks time locally and resynchronizes from media state updates.
Lookups are cancelled on relevant track/config changes, with requests spaced at
least 350 ms apart and an eight-second HTTP timeout. HTTP errors are reported;
lookup success and player seek support should be checked independently.
