# Extensions natives

Les extensions de 3Decks utilisent un exécutable natif et un protocole JSON Lines borné. Voir le [SDK Rust, le manifeste et l’exemple](../desktop/extension-sdk/README.md). Chaque paquet requiert une approbation locale explicite et s’exécute avec les droits de l’utilisateur. L’ancienne API Python est archivée dans [`legacy/python-agent/docs/EXTENSIONS.fr.md`](../legacy/python-agent/docs/EXTENSIONS.fr.md).
