# 3Decks 1.0.2

This update improves settings persistence, console pairing and notification handling.

## Fixes

- Fixed SD-card settings saves on Nintendo 3DS and 2DS using the native filesystem rename operation, with backup recovery and visible error details (#24).
- Preserved the complete pairing token so a saved console can reconnect without entering another code. Failed token saves now open settings and report the SD error.
- Prevented repeated notification snapshots from replaying the same sound, including after a TCP reconnect. macOS no longer announces older notifications again when newer ones are dismissed.
- Replaced the settings-saved star with a green checkmark.
- Clarified that remote audio output switching is unavailable on Windows instead of suggesting that enabling a feature would unlock it (#25). This update does not add Windows output switching.
- Exposed Windows-key shortcuts in the editor.
- Fixed the macOS loopback network test's nonblocking mock socket.

## Downloads

- **Nintendo 3DS / 2DS:** `deck3ds.3dsx` for Homebrew Launcher; `deck3ds.cia` for HOME Menu installation through FBI.
- **macOS Apple Silicon:** `3Decks_1.0.2_aarch64.dmg`.
- **macOS Intel:** `3Decks_1.0.2_x64.dmg`.
- **Windows x64:** `3Decks_1.0.2_x64-setup.exe`.

The `.sig` files and `latest.json` are used by the desktop updater. `SHA256SUMS.txt` lists the download checksums.

macOS packages use ad-hoc signing; Windows installers do not have an Authenticode signature. Windows notification access requires an MSIX package identity and is unavailable in the standalone installer. Linux packages are not included.
