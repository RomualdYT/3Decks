# 3Decks 1.0.2

More reliable saves, automatic reconnection and notifications that only ring once. This update fixes several issues reported by the community on Nintendo 3DS and 2DS.

## What's improved

- **Settings save correctly:** fixed the “Could not save to SD card” error. A green checkmark now confirms that your settings are saved.
- **Pair once, reconnect automatically:** your console remembers the pairing so you don't have to enter it every time you open 3Decks.
- **No more repeating notification sounds:** the same notification no longer rings over and over, and dismissing a notification on macOS won't make an older one ring again.
- **Windows-key shortcuts:** you can now choose the Windows key when creating shortcuts in the editor.
- **Clearer audio messages on Windows:** unsupported audio output actions no longer incorrectly ask you to enable a feature.

## Which files do I need?

Download one file for your computer and one for your console:

| Device | File |
| --- | --- |
| Windows PC | `3Decks_1.0.2_x64-setup.exe` |
| Mac with Apple Silicon | `3Decks_1.0.2_aarch64.dmg` |
| Mac with Intel processor | `3Decks_1.0.2_x64.dmg` |
| 3DS / 2DS — Homebrew Launcher | `deck3ds.3dsx` |
| 3DS / 2DS — HOME Menu (install with FBI) | `deck3ds.cia` |

New to 3Decks? Follow the [installation and pairing guide](https://github.com/RomualdYT/3Decks/blob/main/docs/INSTALLATION.md).

Thanks to everyone who reported bugs and helped test the fixes!
