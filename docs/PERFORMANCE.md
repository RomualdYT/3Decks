# Performance

Measure idle CPU, memory and battery on real machines and a real 3DS before declaring performance targets met. Keep the Tauri webview closed while measuring background network and tray cost, then repeat with the editor open. For console drawing costs, use the host tests and devkitPro build, followed by a hardware frame-time and battery check. Avoid comparing debug and release binaries. Record OS, hardware, feature toggles and sampling duration with results.
